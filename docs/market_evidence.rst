Открытые источники и RAG
========================================

Сервис объединяет MCP с RSS/Atom, HTML и текстовыми PDF. Стандартный реестр
содержит ленту Интерфакса и финансовую отчётность Сбербанка за 2025 год.
Обе загрузки проверены на реальных публичных ответах. Контрольные метаданные
и хеши содержатся в ``tests/fixtures/open_source_contracts.json``.

`Лента Интерфакса <https://www.interfax.ru/rss.asp>`_,
`отчёт Сбербанка <https://www.sberbank.com/common/img/uploaded/files/info/reporting_q4_aolql6na_2025.pdf>`_.

Настройка реестра
----------------------------------------

``EVIDENCE_SOURCES`` задаёт путь JSON-файла. При отсутствии настройки
используется стандартный реестр. Пустой массив отключает открытые каналы.

.. code-block:: json

   [
     {
       "id": "sber-ifrs-2025",
       "name": "Сбербанк · МСФО",
       "url": "https://www.sberbank.com/common/img/uploaded/files/info/reporting_q4_aolql6na_2025.pdf",
       "format": "pdf",
       "instrument_ids": ["SBER", "SBERP"],
       "reporting_period": "2025",
       "refresh_seconds": 86400,
       "max_bytes": 20000000
     }
   ]

``id`` уникален в реестре. ``format`` принимает ``rss``, ``html`` или ``pdf``.
Адрес загрузки использует HTTPS. Для новостной ленты инструмент может
определяться по подтверждённым именам общего публичного каталога брокера.
Этот каталог общий для пользователей. Состав личного счёта применяется
при выборе релевантных материалов из индекса.

``EVIDENCE_CA_FILES`` содержит пути доверенных сертификатов через запятую.
По умолчанию используются пути ``TINVEST_CA_FILES``. HTTP-клиент источников
создаётся отдельно от брокерского клиента.

Версии, даты и качество
----------------------------------------

Содержание, исходная ссылка, источник, даты публикации и получения,
период и подтверждённые инструменты сохраняются. Канонизация убирает
параметры отслеживания, сохраняя значимые параметры адреса. Атрибуция
хранит ссылки каждого канала. Повторная загрузка прежнего содержания
сохраняет исходную версию и добавляет наблюдение.

Первое получение подтверждает доступность конкретной версии. Дата
публикации сама по себе не подтверждает неизменность полученного позднее
содержания. Исправленная версия и новая связь с инструментом доступны
с момента их подтверждения. Исторический поиск исключает более поздние
и неизвестные даты. Финансовые факты ссылаются на соответствующую версию.

``pypdf`` сохраняет столбцы текстового PDF. Извлекаются поддержанные
финансовые строки с явными единицами, валютой, стандартом, консолидацией
и периодом. Суммы в тысячах, миллионах и миллиардах нормализуются.
Квартальные и накопленные интервалы сохраняются раздельно. Неоднозначные
ячейки, конфликтующие значения и сканированные документы сопровождаются
состоянием недоступности. Страница и фрагмент остаются доказательством.

Поиск
-----

FTS5 индексирует фрагменты с нормализацией ё/е и распространённых русских
окончаний. Запросы используют безопасные префиксы слов, точные идентификаторы
эмитентов и последнюю версию, доступную на дату. Внешний текст сохраняется
как содержимое источника.

.. code-block:: python

   from investment_journal.evidence_search import search_evidence

   results = search_evidence(repo, "чистая прибыль", ["SBER"], as_of)
   for result in results:
       print(result["document"].url, result["chunk"].page)

``EvidenceService.collect`` объединяет ``fetch_events`` и открытые каналы.
Результат включает ссылки и состояния свежести для пользовательского отчёта.

Обновление
----------

Обычный интервал составляет 30 минут для RSS и сутки для отчётности.
Ошибки временной сети допускают до двух попыток. ``Retry-After``
сохраняется, последующие попытки ограничиваются отложенным сроком.
Кэш, последнее успешное получение и ошибки переживают перезапуск.
При отказе одного канала остальные продолжают сбор. Отчёт показывает
фактическое время кэшированных данных и исходные ссылки.

Проверки
--------

.. code-block:: console

   python -m unittest discover -s tests -p "test_evidence*.py" -v
   python -m unittest discover -s tests -p test_financial_extraction.py -v
   python -m unittest discover -s tests -p test_market_evidence.py -v

Проверка ``test_public_source_original_link_and_freshness_in_delivered_report``
проходит сохраняемую доставку с подменённым источником и проверяет ссылку
публикации и время последней успешной загрузки.
